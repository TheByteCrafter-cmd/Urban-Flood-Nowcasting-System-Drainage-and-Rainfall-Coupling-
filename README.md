# GeoNexus — Urban Flood Nowcasting System (Drainage and Rainfall Coupling)

**SIH 2026 Problem Statement:** SIH26085  
**Team Name:** GeoNexus  

## Overview
High-resolution, real-time urban flood nowcasting system with a 0–3 hour lead time, coupling rainfall nowcasts, 2D surface flow modeling, and 1D underground drainage network hydraulics.

This project is under phased development. See `FRONTEND_PLAN.md` for the approved architecture and implementation roadmap.
